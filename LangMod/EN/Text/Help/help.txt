$About this Mod
Increasing the types of requests on the Request Board. (9 types total)

Each guild will now generate guild-exclusive requests.
(Merchants Guild: 10, Fighters Guild: 9, Mages Guild: 7, Thieves Guild: 8)
Guild-exclusive requests will add guild-specific currency as rewards,
which can be exchanged for prizes once a certain amount is collected.

Also, increasing the maximum number of requests that can be accepted simultaneously to 12.

$Options
You can configure options via:
BepInEx/config/byakko.elin.RandomQuest.cfg in the Elin installation folder.

{topic|Plat rate for requests from citizens}
・You can set the multiplier (%) for bonus plats earned from requests from citizens.
・Setting this to 0 makes the number of bonus platinum coins match the vanilla behavior.

{topic|Limit on the number of requests}
・Set a limit on the number of requests that can be accepted simultaneously.

{topic|Exclude Rune Vessels}
・Gears generated through requests or the guilpo exchanger has a small chance of coming with a Rune Vessel.
・If set to false, the Rune Vessel is excluded from the list of possible enchantments.

{topic|Enable the strong doggo}
・The level of the werewolf in the werewolf hunting request scales by fame, but it is capped at 2500.
・If set to true, removes the cap, unleashing a terrifying doggo that will devastate the city at breakneck speed.
